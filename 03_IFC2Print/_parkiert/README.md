# _parkiert – Code für spätere Stufen

Hier liegt Code, der erst ab Stufe 2/3 gebraucht wird. Die Ordnerstruktur
entspricht dem Projekt: zum Aktivieren einfach 1:1 zurückschieben.

| Datei/Ordner | Zurück nach | Ab Stufe |
|---|---|---|
| `db/` (datenbank.py, schema.sql, seed/) | `db/` | 2 – Regeln in SQLite |
| `core/aufteilung.py` | `core/` | 3 – Geschosse + Steckzapfen |
| `core/export.py` | `core/` | 3 – 3MF-Export |

Nichts im aktiven Code importiert aus diesem Ordner.
